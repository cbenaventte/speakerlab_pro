# SpeakerLab Pro — identidad inicial

**Concepto:** ingeniería acústica accesible para diseñar, simular y construir cajas acústicas.

**Lema:** Diseña. Simula. Construye.

## Símbolo

El isotipo combina tres elementos: medio cono de altavoz, una curva de respuesta en frecuencia y el monograma SL. La curva naranja representa la simulación y la toma de decisiones técnicas.

## Colores

| Uso | Color | Hex |
|---|---|---|
| Principal | Grafito | `#171A1F` |
| Acento | Naranja | `#F47A21` |
| Fondo claro | Marfil | `#F4F1EA` |
| Secundario | Gris técnico | `#69707A` |

## Tipografía

Para la interfaz se recomienda **Inter**. Como alternativa, **Montserrat** para títulos y **Arial** como respaldo del sistema.

## Archivos

- `speakerlab-pro-logo.svg`: logo horizontal para fondos claros.
- `speakerlab-pro-logo-dark.svg`: variante preparada para fondos oscuros.
- `speakerlab-pro-mark.svg`: isotipo independiente.
- `favicon.svg`: versión simplificada para navegador y accesos directos.

## Uso mínimo

No estirar, rotar, recolorear parcialmente ni añadir sombras o brillos. Mantener alrededor del logo un margen libre equivalente, como mínimo, a la mitad del diámetro del centro del altavoz.

En una web, usar el logo horizontal a una altura aproximada de 40–56 px y el isotipo desde 28 px. Para tamaños menores, usar exclusivamente `favicon.svg`.
